# node-site-templates

Сайты-прикрытия («заглушки») для нод Remnawave. nginx ноды отдаёт выбранный шаблон на домене,
чтобы прямой заход на адрес показывал обычный сайт.

Каждый шаблон — папка в `sites/<name>/` с `index.html` и ассетами. Список — в `templates.json`.
Установщик ноды (`deploy/node-setup/install-node.sh` в remna-net) скачивает тарбол этого репозитория
и раскладывает `sites/<name>/` в `/var/www/html`; `<title>` рандомизируется на каждой ноде.

Добавить шаблон: положить папку в `sites/`, добавить запись в `templates.json`, запушить.
